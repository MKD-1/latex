\section*{How To Use This Repository}
\addcontentsline{toc}{section}{How To Use This Repository}

This document is generated from independent section files and standalone C++
source files. Keep algorithm explanations in \texttt{sections/}, keep code in
\texttt{code/}, and include code with \verb|\lstinputlisting|.

\begin{CompactItemize}
  \item \texttt{main.tex}: root entry point.
  \item \texttt{styles/acm.sty}: shared layout, code style, and helper commands.
  \item \texttt{sections/*.tex}: algorithm category chapters.
  \item \texttt{code/*.cpp}: standalone C++ templates.
\end{CompactItemize}
